# Cupertino · 《购物车日记》

IDN®理想营养小红书官号双 11 短视频《购物车日记》（主题 2）的 Blender 制作备份。

一瓶 D3K2 在购物车里等了一年，主人总有借口不下单，双 11 终于结算。竖屏 1080×1920，30fps。

## 当前状态（2026-10-20）

- **`blender-project/双11-购物车日记.blend` 是修改前的基线版本**：镜 1–5（时间线帧 1–510）。贴图已经打包进文件，下载后单独这一个文件就能打开。
- **新的灯光方向已确认，但只做了静帧**：采用「A 灯光细调」的 02 柔化阴影版本（见 `文档/灯光A细调/`）。这套灯光**还没有用到正式工程和动画里**。
- `blender-project/镜1-5-预览-含音效.mp4` 是基线版本的预览（半分辨率，17 秒），用的是旧灯光。
- **下一步**：按已确认的灯光方向和讨论纪要，重新制作镜 1–5；之后再逐镜确认镜 6–10。
