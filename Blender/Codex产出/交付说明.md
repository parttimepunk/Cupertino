# 双11收银台立牌｜美式复古得来速

推荐 A 奶油白搪瓷版：奶油白主体、樱桃红印字、四芒星、拱顶轮廓和带灯右箭头。B 为同结构的樱桃红配色备选。奶油白版在蓝色购物车与黄色标签之间更克制。

## 文件

- `A_奶油搪瓷箭头_正面.png`：主推牌面，2400×1900，RGBA 透明底，正面无透视。
- `B_樱桃红复古箭头_正面.png`：红底配色，尺寸与结构相同。
- 两份 `*_发光层.png`：与各自牌面完全同画布、同坐标，只含五颗灯芯；不裁切、不自动居中，不含烘焙光晕。
- `A_完整立牌_材质效果参考.png`：内置 imagegen 生成的材质与造型参考。用于观察搪瓷、金属包边和底座质感；生成图的比例及细节以正式牌面、模型和下述尺寸为准。
- `A_收银台立牌_独立模型.blend`：独立立牌资产，未改动原视频工程；贴图已打包。
- `A_完整支架_未亮灯.png`、`A_完整支架_亮灯.png`：独立模型的实际渲染。
- `过程文件/`：牌面制作源脚本、建模源脚本、灯泡坐标、200px可读性样张、参考视频抽帧及生成提示词。

## 建议结构与材质

总高约22cm；实体牌面宽约7.6cm、高约5.8cm，金属厚约1.5mm。细镍色金属杆直径2.5mm；椭圆配重底座约4.5×2.8cm、高8mm。边缘只做轻微磨损，不加密集锈斑。中文和英文为平面丝印，不必做厚重凸字。

配色：奶油白 #F6E9C9、樱桃红 #A72D2B、深棕边 #66342C、灯座黄铜 #C29B52。

## Blender 使用

1. 通过“文件 → 追加”导入独立模型中的立牌、包边、杆、底座、灯泡；摄影棚、相机和灯光只是预览环境，按需导入。
2. 使用米制比例。牌面与发光层共用同一组UV，完整画布2400×1900，透明边距也要保留。用PNG作平面时必须连接 Alpha；模型已有真实异形轮廓。
3. 正面PNG是无光照的平面设计，不包含场景阴影；灯泡玻璃与厚度由模型提供。
4. 独立模型第1帧为灯灭，第59帧仍灭，第60帧亮起，第90帧保持；这是可移动的示例关键帧，导入后挪到实际越线“叮”的时刻。
5. 仅五颗箭头灯泡发光，文字不发光。发光强度按正式场景曝光调整，避免冲淡箭头。
6. B版只需把牌面材质贴图换成B版正面PNG，发光坐标相同。
